# Agentic skills for CLI and app clients

Developed by the LetsCookTech Open Source Team.

AI Engineering Arsenal skills are Markdown-first operating frameworks for CLI agents, app agents, IDE agents, and future agentic development environments.

## Target clients

| Client type | Usage pattern |
| --- | --- |
| Codex | Put the skill folder in a discoverable skills directory or paste `SKILL.md` into the task. |
| Claude Code / Claude Projects | Attach or install the skill as reusable project context. |
| ChatGPT / Gemini | Paste the skill or load it as project/instruction context. |
| Cursor / Windsurf | Convert core workflow into rules and keep benchmark docs in repo. |
| Cline / Roo Code | Use the skill as task-mode operating instructions. |
| Aider | Use as review instructions before code generation or refactor planning. |
| Antigravity-style agentic IDEs | Use the skill as an operating contract: intake, analysis, verification, risk review, implementation, and final artifact. |

Use [`agentic-skill-pack-integrator`](../skills/agentic-skill-pack-integrator) for imports.
