# Runnable paired evaluations (experimental)

AI Engineering Arsenal can now score human-reviewed rubric dimensions with strict input validation and compare two **hash-pinned raw agent output artifacts**. The tool does not run a model or claim to objectively measure AI reliability.

## Use

Python 3.11+ (standard library only). From the repository root:

```bash
python scripts/validate.py
python -m unittest discover -s tests -v
python scripts/score_evaluation.py examples/paired-evaluation/score-example.json
python scripts/compare_evaluations.py examples/paired-evaluation/manifest.json
```

**The included example is purely synthetic.** Its outputs were authored, not generated by Codex, and its scores were chosen to demonstrate arithmetic. It is not a benchmark win.

## Preparing a real comparison

1. Select a sanitized task and define its expected outcome independently of model output.
2. Run the same model/version and controls twice: baseline, then with the candidate Arsenal skill. Record exact configuration and run logs.
3. Save each raw response to a separate nonempty text file, no larger than 10 MiB.
4. Have an independent reviewer score the 11 dimensions, 0–10, and preserve their notes.
5. Record SHA-256 of the original input task and both raw outputs; fill the manifest with the real control values and evaluator identifier.
6. Run the comparison CLI. Inspect raw evidence, reviewer disagreements, and any critical-dimension regressions.
7. Publish both wins and losses, overhead, failure cases and limits, and repeat on held-out tasks before claiming effectiveness.

## What is enforced

- No booleans, NaN, infinity, missing or unknown rubric dimensions or out-of-range values.
- Relative artifact paths stay inside the manifest directory, and files must match specified SHA-256 hashes.
- A drop in accuracy, evidence, verification or security is labeled `CRITICAL_REGRESSION`, even if weighted total rises.
- No execution of contributed artifacts, network access, uploads, or third-party dependencies.

## What is not enforced

The evaluator identity, objectivity of scores, actual model/temperature matching, independence of the scorer, task correctness, origin authenticity, and tamper resistance. Anyone who controls the manifest and artifacts can replace them and update the hashes. Human-reviewed evidence and trusted CI are needed for higher assurance.
